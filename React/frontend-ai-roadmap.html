01
Months 0–3

The Foundation

⏱ 3 months · Complete Beginner → HTML/CSS/JS Basics

Every skyscraper starts underground. This phase is about wiring your brain for programming logic and building the raw materials of the web — HTML structure, CSS styling, and JavaScript behavior.

Core Skills
🌐
HTML Fundamentals
  • Document structure: DOCTYPE, head, body
  • Semantic elements: header, nav, main, section, article, footer
  • Forms: input, select, textarea, labels, buttons
  • Tables, lists, images, links
  • HTML5 APIs: video, audio, canvas basics
  • Accessibility: ARIA roles, alt text, tab order
🎨
CSS Fundamentals
  • Selectors: tag, class, ID, attribute, pseudo
  • Box model: margin, border, padding, content
  • Display: block, inline, inline-block, none
  • Positioning: static, relative, absolute, fixed, sticky
  • Flexbox — the most important layout tool
  • CSS Grid basics
  • Colors, fonts, units (px, %, rem, em, vh, vw)
⚡
JavaScript Basics
  • Variables: var, let, const
  • Data types: string, number, boolean, array, object
  • Functions, scope, hoisting
  • Control flow: if/else, switch, ternary
  • Loops: for, while, forEach, map, filter
  • DOM manipulation: querySelector, addEventListener
  • Basic async: setTimeout, fetch API
🛠️
Dev Environment
  • VS Code setup + essential extensions
  • Browser DevTools: Elements, Console, Network tabs
  • Git basics: init, add, commit, push, pull
  • GitHub: create repo, clone, README
  • Command line basics: cd, ls, mkdir, touch
  • Node.js & npm: install, run scripts
Milestone Projects
🧾 Personal Profile Page
A static HTML/CSS page with your photo, bio, and links. Practice semantic HTML + Flexbox layout.
HTML + CSS
🌦️ Weather Display
Hardcoded weather data displayed with CSS cards. Practice CSS Grid and responsive units.
HTML + CSS
🖩 JavaScript Calculator
A working calculator in the browser. Practice DOM events, functions, and logic.
JS + DOM
📝 Todo List App
Add, delete, and complete tasks stored in a JS array. Classic beginner full-feature project.
JS + LocalStorage
Resources
freeCodeCamp.org MDN Web Docs The Odin Project css-tricks.com javascript.info Flexbox Froggy CSS Grid Garden
✅ Phase Complete When You Can…
✓
Build a multi-section webpage from scratch without looking up basic HTML tags
✓
Center anything on the screen using Flexbox without Googling it
✓
Write a JS function that takes input and returns output with conditionals
✓
Push a project to GitHub with a proper README
💰 Market Rate Not job-ready yet Keep building. This phase is pure investment.
02
Months 3–9

Core Frontend Dev

⏱ 6 months · Fundamentals → Framework-Ready

This is where you go from "I understand HTML" to "I can build real things." You'll learn responsive design, modern JavaScript, your first framework (React), and how real software teams work.

Core Skills
📐
Responsive Design
  • Mobile-first approach and methodology
  • Media queries: breakpoints, min/max-width
  • CSS Grid: template areas, auto-fill, minmax
  • Responsive images: srcset, picture element
  • CSS Custom Properties (variables)
  • CSS transitions and basic animations
  • SASS/SCSS: nesting, variables, mixins
🚀
Modern JavaScript (ES6+)
  • Arrow functions, template literals
  • Destructuring: arrays and objects
  • Spread/rest operators
  • Promises, async/await
  • Modules: import/export
  • Classes and prototypal inheritance
  • Array methods: map, filter, reduce, find
  • Error handling: try/catch/finally
⚛️
React Fundamentals
  • JSX syntax and component architecture
  • Props and state management
  • Hooks: useState, useEffect, useRef
  • Event handling in React
  • Conditional rendering and lists/keys
  • Component lifecycle understanding
  • React Router: navigation, params, routes
  • Fetching data from APIs
🔧
Dev Tools & Workflow
  • Git branching: feature branches, merge, rebase
  • Pull requests, code reviews on GitHub
  • npm scripts, Vite or Create React App
  • ESLint + Prettier for code quality
  • Chrome DevTools: debugging, breakpoints
  • REST APIs: GET, POST, PUT, DELETE
  • Postman or Insomnia for API testing
Milestone Projects
🌍 Responsive Business Site
Multi-page site that works on all screen sizes. Use CSS Grid + media queries. Add a contact form.
HTML + CSS + Responsive
🎬 Movie Search App
Call the OMDB or TMDB API. Search for movies, display results in cards, click for details.
React + API
📊 Finance Tracker
Add income/expenses, show totals, filter by category. Use React state management + local storage.
React + State
💬 GitHub Profile Viewer
Search any GitHub username, display repos, stars, followers using the GitHub API.
React + GitHub API
Tools to Learn
React SASS/SCSS Vite Git / GitHub Postman ESLint Prettier Tailwind CSS Figma (basics)
✅ Phase Complete When You Can…
✓
Build a multi-page React app that fetches real API data and handles loading/error states
✓
Make any site fully responsive without using a framework like Bootstrap
✓
Use Git branching with meaningful commit messages and create pull requests
✓
Debug your own bugs using console + DevTools without immediately Googling the error
💰 Internship / Entry Potential $30k–$55k India: ₹3–8 LPA · US: $40–65k
03
Year 1–2

Junior Developer

⏱ 12–18 months · First Job → Productive Team Member

You're employed. Now the real learning begins. This phase is about surviving and thriving on a real team — understanding codebases you didn't write, shipping features under deadlines, and learning the craft of production code.

Core Skills
⚛️
Advanced React
  • Custom hooks: encapsulate reusable logic
  • Context API for global state
  • useMemo, useCallback for performance
  • Code splitting and lazy loading
  • React Query / TanStack Query for server state
  • Form libraries: React Hook Form, Formik
  • Component composition patterns
🧪
Testing
  • Unit testing with Jest
  • Component testing: React Testing Library
  • Test-driven development (TDD) basics
  • Mocking API calls in tests
  • E2E testing with Cypress or Playwright
  • Code coverage reports
📦
State Management
  • Redux Toolkit: slices, thunks, selectors
  • Zustand: lightweight alternative
  • When to use global vs local state
  • Derived state and memoization
  • Optimistic UI updates
🌐
TypeScript
  • Types vs interfaces
  • Generics and utility types
  • Typing React components and hooks
  • Enums and union types
  • tsconfig and strict mode
  • Type narrowing and guards
🔄
Team & Process Skills
  • Agile/Scrum: standups, sprints, retros
  • Jira or Linear for ticket management
  • Code review etiquette: give and receive feedback
  • Reading other people's code effectively
  • Writing meaningful commit messages
  • Documentation: JSDoc, README updates
🎯
CSS Mastery
  • Tailwind CSS: utility-first deep dive
  • CSS-in-JS: styled-components, Emotion
  • CSS Modules for scoped styles
  • Animation: keyframes, Web Animations API
  • Design tokens and theming systems
  • Storybook for component documentation
Milestone Projects
🛒 E-commerce Store
Product listing, cart with state management, checkout form with validation. Full TypeScript.
React + Redux + TS
📋 Project Management Tool
Kanban board with drag-and-drop. Create, edit, delete tasks. Persist with a real backend or Firebase.
React + Firebase
💬 Real-time Chat App
WebSocket-based messaging with rooms, user presence indicators, and message history.
React + WebSockets
📊 Analytics Dashboard
Charts (Chart.js or Recharts), date range filters, multiple data sources, dark/light mode toggle.
React + Data Viz
Also Learn
TypeScript Jest React Testing Library Redux Toolkit React Query Storybook Cypress Firebase Figma (intermediate) Webpack basics
✅ Phase Complete When You Can…
✓
Write typed React components end-to-end in TypeScript with no "any" types
✓
Write unit and integration tests that give you confidence before deploying
✓
Navigate a large codebase you didn't write and make changes without breaking things
✓
Receive critical code review and improve your code without taking it personally
💰 Junior Developer $55k–$85k India: ₹6–15 LPA · US: $65–95k
04
Year 2–5

Mid-Level Engineer

⏱ 2–3 years · Reliable contributor → Technical decision maker

This is the longest and most transformative phase. You shift from executing tasks to owning systems. You start to see the full picture: performance, scalability, architecture, and team velocity. Others start asking for your opinion.

Core Skills
🏗️
Frontend Architecture
  • Feature-based folder structure and monorepos
  • Design system architecture and component libraries
  • Micro-frontend patterns
  • Module federation with Webpack 5
  • Nx or Turborepo for monorepo management
  • Dependency injection patterns in frontend
⚡
Performance Engineering
  • Core Web Vitals: LCP, FID, CLS — measure and fix
  • Bundle analysis: webpack-bundle-analyzer
  • Code splitting, tree shaking, lazy loading
  • Image optimization: WebP, AVIF, srcset, lazy
  • Caching strategies: HTTP headers, Service Workers
  • Virtual scrolling for large lists
  • React profiler and performance audits
🔐
Backend & APIs
  • Node.js + Express: build your own REST API
  • GraphQL: queries, mutations, Apollo Client
  • Authentication: JWT, OAuth 2.0, session cookies
  • SQL basics: PostgreSQL queries, joins, indexes
  • ORMs: Prisma or Drizzle
  • REST vs GraphQL vs tRPC trade-offs
☁️
DevOps & Deployment
  • CI/CD pipelines: GitHub Actions
  • Docker: containers, docker-compose
  • Vercel, Netlify, AWS S3 + CloudFront
  • Environment variables and secrets management
  • Error monitoring: Sentry
  • Logging and observability basics
📐
Next.js / Meta-Frameworks
  • App Router vs Pages Router
  • SSR, SSG, ISR — when to use each
  • Server Components and Client Components
  • API routes and middleware
  • Edge runtime and streaming
  • Image and font optimization built-ins
🧠
Engineering Maturity
  • SOLID principles in frontend context
  • Design patterns: Observer, Factory, Singleton, Strategy
  • Refactoring legacy code safely
  • Technical debt: identifying and communicating it
  • Writing technical specs and proposals (RFCs)
  • Mentoring junior developers
Milestone Projects
🏢 Full-Stack SaaS App
Authentication, subscriptions (Stripe), dashboard, user settings. Next.js + Prisma + PostgreSQL.
Next.js + Full Stack
🎨 Component Library
Build and publish a reusable UI library to npm with Storybook docs and full TypeScript types.
React + npm publish
📈 Performance Audit & Fix
Take an existing slow app, audit it with Lighthouse, and document + implement improvements.
Performance Engineering
🔌 GraphQL API
Design a schema, implement resolvers, connect to a DB. Consume from React with Apollo Client.
GraphQL + Node
Ecosystem to Master
Next.js Node.js GraphQL Docker PostgreSQL Prisma GitHub Actions AWS / Vercel Sentry Lighthouse Nx / Turborepo
✅ Phase Complete When You Can…
✓
Design the architecture of a new feature without being told how to approach it
✓
Identify and fix performance issues using profiling tools, achieving measurable gains
✓
Build and deploy a full-stack app with auth, database, and CI/CD pipeline
✓
Mentor a junior developer through a bug or feature without just writing the code for them
💰 Mid-Level Engineer $85k–$130k India: ₹15–35 LPA · US: $100–150k
05
Year 5–7

Senior Engineer

⏱ 2–3 years · Technical authority → Organizational impact

At this level, your impact is no longer measured in features shipped — it's measured in teams elevated, systems made more reliable, and decisions that save months of work. You're a force multiplier.

Core Skills
🏛️
System Design
  • Scalable frontend architecture for large teams
  • Design system governance and versioning
  • Cross-team API contracts and versioning
  • Distributed state management at scale
  • Real-time architectures: WebSockets, SSE, polling
  • CDN strategy and edge computing
  • Offline-first and PWA architecture
🔒
Security & Reliability
  • OWASP Top 10: XSS, CSRF, injection attacks
  • Content Security Policy (CSP) implementation
  • HTTPS, HSTS, certificate management
  • Rate limiting and DDoS mitigation
  • Error boundaries and graceful degradation
  • Feature flags for safe deployments
  • A/B testing frameworks
♿
Accessibility (a11y)
  • WCAG 2.1 AA compliance end-to-end
  • Screen reader testing: NVDA, VoiceOver
  • Keyboard navigation and focus management
  • ARIA patterns for complex widgets
  • Color contrast and visual accessibility
  • axe DevTools and automated a11y CI checks
👥
Leadership & Influence
  • Technical interviews: conducting and designing them
  • Architecture Decision Records (ADRs)
  • Cross-functional collaboration with Product & Design
  • Engineering roadmap contribution
  • Breaking down complex work into sprint-sized tasks
  • Presenting technical trade-offs to non-technical stakeholders
📊
Observability & Ops
  • Real User Monitoring (RUM) with Datadog or New Relic
  • Synthetic monitoring and uptime alerts
  • On-call rotations and incident response
  • Postmortems: blameless and actionable
  • SLOs, SLAs, SLIs for frontend services
  • Kubernetes basics for frontend deployment
🔬
Advanced Patterns
  • Compiler and build tool internals (Rollup, esbuild)
  • Custom Babel/PostCSS plugins
  • Browser rendering pipeline deep dive
  • Memory leak detection and heap profiling
  • WebAssembly (WASM) for performance-critical code
  • Web Workers for off-main-thread computation
Impact at This Level
🏗️ Platform Migration
Lead migrating a legacy Angular app to React/Next.js — plan, execute, and ship without breaking production.
Architecture Leadership
📦 Internal Design System
Create the company's component library. Define tokens, patterns, governance. Used by multiple teams.
Design Systems
🚀 Performance Initiative
Improve app-wide Core Web Vitals scores. Measurable business impact (conversion, retention).
CWV + Business Metrics
🧑‍🏫 Engineering Guild
Start or lead a frontend guild. Weekly tech talks, shared best practices, cross-team code standards.
People Multiplier
✅ Phase Complete When You Can…
✓
Own an entire system end-to-end — from architecture to deployment to on-call
✓
Influence engineering culture through writing, talks, or standards that others adopt
✓
Say no to bad ideas with data and alternatives, and have people respect that
✓
Onboard a new team member from zero to productive in under two weeks
💰 Senior Engineer $130k–$200k India: ₹35–80 LPA · US: $140–250k+
06
Year 7–8+ · The Frontier

AI-Integrated Expert

⏱ Ongoing · Senior → AI-Native Frontend Expert & Architect

The final phase doesn't have a finish line. This is where your years of deep frontend mastery meet the explosive world of Generative and Agentic AI. You don't just use AI tools — you build products powered by them.

Generative AI Skills
🤖
LLM API Integration
  • OpenAI, Anthropic Claude, Google Gemini APIs
  • Prompt engineering: system prompts, few-shot examples
  • Streaming responses with Server-Sent Events
  • Function calling / tool use with LLMs
  • Token management and cost optimization
  • Model selection: trade-offs of speed vs quality vs cost
  • Fine-tuning concepts and when to use them
🔗
RAG & Knowledge Systems
  • Embeddings: what they are and how to generate them
  • Vector databases: Pinecone, Weaviate, pgvector
  • Retrieval-Augmented Generation (RAG) pipeline
  • Chunking strategies for documents
  • Semantic search implementation
  • Hybrid search: keyword + semantic
🕸️
Agentic AI Systems
  • LangChain / LangGraph for agent workflows
  • Multi-agent orchestration patterns
  • Tool use: giving AI access to APIs, databases
  • Human-in-the-loop design patterns
  • Agent memory: short-term, long-term, episodic
  • Evaluation and testing AI agents
  • MCP (Model Context Protocol) integrations
🎨
AI-Powered UI Patterns
  • Chat interfaces with streaming + markdown rendering
  • AI copilot sidebars and inline suggestions
  • Vercel AI SDK for React/Next.js apps
  • Progressive loading for AI responses
  • Feedback loops: thumbs up/down, regenerate
  • Responsible AI UI: citations, confidence, disclaimers
🐍
Python for AI
  • Python fundamentals for scripting and automation
  • FastAPI: build AI backend services
  • LangChain, LlamaIndex, CrewAI frameworks
  • Jupyter notebooks for prototyping
  • Data manipulation with pandas
  • Deploying Python microservices to cloud
🎯
AI Product Strategy
  • Identifying where AI adds genuine value vs hype
  • AI evaluation: accuracy, latency, cost metrics
  • Guardrails and content moderation for AI outputs
  • Privacy: what data can/can't go to LLM APIs
  • AI product metrics: task completion, deflection rate
  • Prompt injection and AI security concerns
Expert-Level Projects to Build
🧠 AI Research Assistant
Upload PDFs, embed them in a vector DB, ask questions. Full RAG pipeline with streaming chat UI.
RAG + React + Python
✍️ AI Writing Copilot
Inline suggestions, tone rewriting, auto-complete. Like Notion AI built from scratch.
LLM + Rich Text Editor
🤖 Autonomous AI Agent
Agent that browses the web, reads emails, and creates Jira tickets. Multi-step, multi-tool workflow.
Agentic AI + LangGraph
🏢 Enterprise AI Chatbot
Company knowledge base chatbot with auth, usage analytics, prompt guardrails, and admin UI.
Production AI System
🔊 Voice AI Interface
Real-time voice input/output with Whisper + TTS. Build a voice-first AI assistant in the browser.
Speech + LLM + WebRTC
🎨 AI Design Tool
Describe a UI in natural language, generate React components in real time. Like v0.dev but custom.
Code Generation + AI
